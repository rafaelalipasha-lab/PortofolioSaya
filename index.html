Tentang Saya

Saya percaya bahwa teknologi adalah salah satu bidang yang akan terus berkembang dan memberikan banyak peluang di masa depan. Saat ini saya sedang mempelajari berbagai bahasa pemrograman dan teknologi web, seperti HTML, CSS, dan JavaScript, sebagai dasar untuk menjadi seorang web developer sekaligus game developer.
